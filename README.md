## The joke

> I asked IT for a second monitor and got a lecture on mindfulness instead — apparently the screen I need is inner peace.

One line, 119 characters. An IT request for a second monitor earns a
mindfulness lecture instead, and the punchline turns the word "screen"
into "inner peace" in the last few words.

## How it works

`main.py` (Python 3, standard library only) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and
self-checks it first: one line, 1–200 characters, not only white space.

```sh
python3 main.py
```
